# 在智控台导入人格 Skill

进入「智能体管理 → 目标智能体 → 配置角色」，在「角色介绍」下方点击「导入人格 Skill」，直接选择本机 ZIP／`.skill` 人格包。预览全文及实际采用的文件后点击「填入角色介绍」，再点击页面的「保存配置」。取消预览不会更改当前角色；填入后尚未保存时，服务器配置也不会改变。

压缩包可以直接包含文件，也可以包一层目录。入口识别规则：

1. 同一入口目录有 `full-system-prompt.txt` 时，优先使用已经合并的完整正文。若同时有 `agent-patch.json`，核对两份正文一致，不重复拼接原始档案。
2. 只有 `agent-patch.json` 时，只读取其 `systemPrompt` 字符串。
3. 只有 `SKILL.md` 时，读取其正文，再检查同目录的 `persona.md`、`memories.md`；未包含的内容追加，已经完整包含的文件不重复加入。

外层入口确定后，内层 `source`、历史版本中的入口作为参考，不自动切换角色。若没有入口或发现多个独立人格目录，则停止导入并提示。隐藏目录和 macOS 附带元数据不作为入口。

预览会列出正文来源、一致性校验文件、已包含的档案和未加入正文的文件数量。聊天记录、图片、证据与脚本不自动作为知识库导入，也不执行任何代码。仅自动组合前述文件；其他相对引用不会自动加载。

仍支持直接选择以下 UTF-8 文本文件：

- `SKILL.md` 或其他 `.md`：导入完整 Markdown 正文。文件开头存在包含 `name` 或 `description` 的 Skill 注册信息时，移除该部分并在预览中提示。
- `.txt`：保留完整正文和换行。
- `.json`：只读取字符串字段 `systemPrompt`，例如 `{"systemPrompt":"完整人格与共同记忆正文"}`。其他字段不会用于覆盖模型、音色、记忆或插件设置。

`.skill` 按 ZIP 包处理，支持普通单卷、未加密的 ZIP（存储或 Deflate 压缩），文件名使用 UTF-8；7z、RAR、tar.gz 需要先转换为 ZIP。压缩包最多 8 MiB、256 项，声明展开大小合计最多 16 MiB。目录条目也计入项数，拒绝路径穿越、重名路径、符号链接、分卷和 ZIP64。

角色介绍已取消原有 2,000 字限制，按现有数据库 TEXT 字段的 UTF-8 容量限制为 65,535 字节。页面和预览均显示字符数、字节数；超过容量时停止导入或保存，不进行截断。单个待解析文件最多 256 KB，以容纳 JSON 转义和 Skill 注册信息。无效编码、空正文、无效字符和缺少 `systemPrompt` 的聊天 JSON 会给出错误提示。

压缩包在浏览器内读取目录，仅对需要的人格文件限量解压，并检查实际长度与 CRC32。不会将包内路径解压到磁盘，也不会将整个 ZIP 保存在服务器。只有保存配置时才通过当前登录用户的 `PUT /xiaozhi/agent/{id}` 请求提交选定的角色正文。保存权限、配置版本和设备更新行为沿用现有智能体配置流程。保存后重新建立设备会话以使用新配置；既有连接可能仍持有旧提示词缓存。

无需增加数据库表或 Python 运行时接口。部署时需要更新包含该入口的智控台前端；`--server-only` 只更新 Python 服务，不会安装网页上传入口。

解压依赖：[fflate 官方文档](https://github.com/101arrowz/fflate)。ZIP 目录与校验字段依据：[PKWARE ZIP 格式规范](https://pkware.cachefly.net/webdocs/casestudies/APPNOTE.TXT)。

验证：在 `main/manager-web` 执行 `node --test tests/personaSkill.test.mjs`。测试覆盖完整长正文、ZIP／`.skill` 入口和配套档案组合、去重、版本冲突、实际解压容量、CRC 损坏、路径与 UTF-8 边界、取消/延迟读取、角色配置请求和其他字段保留。
