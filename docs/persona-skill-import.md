# 在智控台导入人格 Skill

进入「智能体管理 → 目标智能体 → 配置角色」，在「角色介绍」下方点击「导入人格 Skill」，选择本机文件。预览全文后点击「填入角色介绍」，再点击页面的「保存配置」。取消预览不会更改当前角色；填入后尚未保存时，服务器配置也不会改变。

支持以下 UTF-8 文本文件：

- `SKILL.md` 或其他 `.md`：导入完整 Markdown 正文。文件开头存在包含 `name` 或 `description` 的 Skill 注册信息时，移除该部分并在预览中提示。
- `.txt`：保留完整正文和换行。
- `.json`：只读取字符串字段 `systemPrompt`，例如 `{"systemPrompt":"完整人格与共同记忆正文"}`。其他字段不会用于覆盖模型、音色、记忆或插件设置。

压缩包需要先解压，再选择已经整理完整的人格正文。此入口不执行 Skill 脚本、不自动展开引用文件，也不用于上传原始聊天记录。若人格依赖其他人物档案或共同记忆文件，请先整理为完整正文；原始聊天资料通过知识库管理。

角色介绍已取消原有 2,000 字限制，按现有数据库 TEXT 字段的 UTF-8 容量限制为 65,535 字节。页面和预览均显示字符数、字节数；超过容量时停止导入或保存，不进行截断。单个待解析文件最多 256 KB，以容纳 JSON 转义和 Skill 注册信息。无效编码、空正文、无效字符和缺少 `systemPrompt` 的聊天 JSON 会给出错误提示。

文件在浏览器中解析并以普通文本预览，只有保存配置时才通过当前登录用户的 `PUT /xiaozhi/agent/{id}` 请求提交角色介绍。保存权限、配置版本和设备更新行为沿用现有智能体配置流程。保存后重新建立设备会话以使用新配置；既有连接可能仍持有旧提示词缓存。

无需增加数据库表或 Python 运行时接口。部署时需要更新包含该入口的智控台前端；`--server-only` 只更新 Python 服务，不会安装网页上传入口。

验证：在 `main/manager-web` 执行 `node --test tests/personaSkill.test.mjs`。测试覆盖完整长正文、UTF-8 容量边界、取消/延迟读取、错误文件、角色配置请求和其他字段保留。
